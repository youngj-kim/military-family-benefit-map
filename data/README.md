# 보완 좌표

`location-overrides.json`은 병무청 원본에 좌표가 없는 시설 중 카카오 주소 검색 결과의 **도로명과 건물번호가 일치**하는 시설의 주소 좌표입니다. 건물 주소 좌표이며 시설 출입구나 입점 층을 검증한 것은 아닙니다.

기존 공식 좌표는 변경하지 않습니다. 병무청 원본 `dist/facilities.json`도 Git에서는 그대로 보존하고, Pages 배포 산출물을 만들 때만 `scripts/apply-location-overrides.cjs`로 합성합니다. 따라서 원본 변경 감지와 보완 좌표가 서로 덮어쓰지 않습니다.

시설 ID뿐 아니라 원본 시설명과 주소가 현재 자료와 같은 경우에만 적용합니다. 공식 좌표가 생기거나 시설명/주소가 바뀌면 해당 보완 좌표는 자동 제외합니다. 관청·담당 부서 주소, 여러 지점의 포괄 혜택, 주소가 불분명한 시설은 자동 보완하지 않았습니다.

2026-10-16 검토: 주소 있는 247건 중 119건 보완, 128건 추가 검토. 주소 없는 124건은 보완하지 않았습니다.

재조회: Actions의 **Geocode missing facility addresses**를 수동 실행하면 후보 아티팩트를 생성합니다. 결과를 검토한 뒤 이 파일을 교체해야 반영됩니다. `KAKAO_REST_API_KEY` Secret은 Actions에서만 사용하며 결과 파일이나 웹사이트에 저장하지 않습니다.

## 검증된 원본 위치 오류 보정

`verified-official-location-correction`은 시설 공식 안내와 연결된 지도 장소로 확인한 오류만 보정합니다. ID·시설명·원본 주소·원본 위도와 경도가 모두 일치할 때만 적용하며 원본이 바뀌면 자동 제외합니다. 보정 주소·좌표는 배포 산출물에만 반영하고 원본 주소·좌표와 검증 출처도 보존합니다. 아르코예술극장(ID 3544)은 공식 오시는 길과 카카오 장소 10593353을 확인해 서해를 가리키는 원본 경도 및 잘못된 원본 주소를 보정했습니다.

## 이름 기반 공공시설 보완

보건소와 읍·면·동이 명시된 주민센터는 `geocode-public-facilities.cjs`로 카카오 REST 키워드 검색을 수행합니다. 전체 검색 결과 안에서 시설명과 관할 지역이 일치하는 장소가 유일한 경우만 별도 보완값으로 저장합니다. 시·군·구 전체 주민자치센터 같은 포괄 항목과 여러 후보는 자동 제외합니다. 카카오 검색 결과의 주소와 좌표이며 공식 원문 정보는 보존합니다. 원본 자료 갱신이 main에 반영되면 재수집하며 Actions에서 수동 실행도 가능합니다. 결과는 `reports/public-facility-geocoding.json`에 기록합니다.
