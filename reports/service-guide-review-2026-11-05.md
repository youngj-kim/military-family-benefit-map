# 예우맵 제도·신청·서비스 고지 검토

검토일: 2026-11-05. 아래는 문안 검토 기록입니다. 이 검토를 바탕으로 `guide.html`에 제도·신청 안내를, `service.html`에 서비스·데이터 안내를 작성했습니다. 지도 상단과 검색 영역에서 연결합니다.

## 결론과 배치

지도 상단에 `제도·신청 안내`, 하단에 `서비스·데이터 안내` 링크를 두는 구성이 적절합니다. 비공식 서비스라는 짧은 설명은 하단에서 항상 확인할 수 있게 합니다. 처음 접속할 때 법적 고지 팝업을 강제로 열 필요는 없습니다.

비공식 안내는 공공기관의 공식 서비스로 오해하지 않도록 권장하는 표시입니다. 첨부 예시와 동일한 문구가 법적으로 반드시 필요하다고 확인한 것은 아닙니다. 서비스 책임을 전부 면제한다는 문구도 넣지 않습니다.

## 제도·신청 안내 초안

### 병역명문가란?

병무청이 3대 가족의 현역복무 등 병역이행을 확인해 선정하는 가문입니다. 가족 범위에는 조부, 부·백부·숙부, 본인·형제·사촌형제가 포함됩니다. 3대에 남성이 없고 여성이 현역 의무복무기간을 마친 경우 등 별도 기준도 있습니다. 최종 대상 여부는 병무청 기준과 심사로 확인합니다.

### 신청은 어디서 하나요?

연중 신청할 수 있습니다. 온라인은 병무청 누리집의 `병무민원 → 병역명문가 → 병역명문가 신청`을 이용하며, 공식 안내에는 e-병무지갑 앱 설치와 간편인증이 안내되어 있습니다. 지방병무(지)청 방문·우편 접수도 가능합니다.

신청서·개인정보 수집이용 동의서·제적등본·가족관계증명서 등이 필요하고, 계속 복무 중인 장교·부사관 등이 있으면 복무확인서가 추가될 수 있습니다. 가족 상황별 발급 범위와 최신 서식은 공식 안내에서 확인합니다. 신청과 표창 심사의 일정은 구분합니다.

예우맵에서는 신청서를 접수하거나 가족관계·병역 서류를 수집하지 않습니다. 신청 버튼은 병무청 공식 서비스로 연결합니다.

### 선정되면 모든 가족이 모든 시설에서 할인받나요?

시설별 적용 대상·동반 범위·증빙이 다르므로 원문과 시설에 확인해야 합니다. 특히 영외마트 목록을 지도에 표시한다고 병역명문가 가족 모두의 이용 자격을 보장하는 것은 아닙니다. 영외마트는 국군복지포털의 이용 기준도 확인하도록 연결합니다.

출처: [병무청 2026년 신청 안내](https://www.mma.go.kr/board/board/boardView.do?gesipan_id=2&gsgeul_no=1521392&mc=usr0000379), [병역명문가 명예의 전당](https://www.mma.go.kr/hall/), [국군복지포털](https://www.welfare.mil.kr/).

## 지도 하단 짧은 고지 초안

> 예우맵은 병무청 공식 서비스가 아닌 개인 운영 지도입니다. 공개자료를 바탕으로 시설을 안내하며, 실제 이용 대상·혜택·운영 여부는 공식 안내와 해당 시설에서 확인해 주세요.

이 설명과 함께 `제도·신청 안내`, `서비스·데이터 안내`, `공식 원문`을 연결하는 방식을 권장합니다.

## 서비스·데이터 안내에 넣을 내용

| 항목 | 현재 구현에 맞는 안내 |
| --- | --- |
| 운영 주체·역할 | 개인 운영 비공식 서비스. 선정·신청·이용 자격 판정을 대행하지 않음 |
| 자료와 정확성 | 병무청 예우시설 및 국방부 영외마트 공개자료의 출처별 기준일 안내. 주소 기반 보정 좌표와 실시간 운영정보를 구별 |
| 현재 위치 | `내 위치 기준`을 눌러 권한을 허용한 경우에만 주변 지도·거리 정렬에 사용. 자체 백엔드에 위치를 저장하는 기능은 없음. 권한을 거부해도 검색 가능 |
| 브라우저 저장 | 즐겨찾기 시설 식별자와 읽은 업데이트 ID를 localStorage에 저장. 같은 브라우저·주소에서 유지되며 사이트 데이터 삭제로 제거 가능 |
| 외부 서비스 | 지도 SDK·지도 이미지 요청은 카카오와 통신. 전화·홈페이지·카카오/네이버 길찾기는 해당 외부 서비스로 연결하며 길찾기 링크에는 현재 위치를 넣지 않음 |
| 호스팅 | GitHub Pages는 보안 목적으로 방문자의 IP를 기록한다고 공식 안내함. 따라서 ‘개인정보를 일절 수집하지 않음’, ‘어떠한 로그도 남지 않음’이라고 표시하지 않음 |
| 정보 수정 제보 | GitHub 로그인 후 공개 이슈 작성. 작성자가 제출한 내용은 공개되므로 이름·연락처·군번·신청서·증빙 서류를 적거나 첨부하지 않도록 안내 |
| 모바일 앱 관련 | 현재는 웹사이트이므로 별도 네이티브 앱의 ‘앱 권한·데이터 안전’ 페이지를 그대로 복제할 필요는 없음. 위치 권한은 웹 안내에 포함 |

GitHub 로그 출처: [GitHub Pages의 데이터 수집 설명](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

## 개인정보 처리방침에 관한 판단 범위

개인정보 보호법 제30조는 개인정보처리자에게 처리방침 수립·공개를 요구합니다. 개인 프로젝트 또는 정적 사이트라는 이유만으로 적용을 면제받는다고 단정할 수 없습니다. 반대로 제3자의 호스팅 로그가 있다는 사실만으로 운영자의 법적 지위와 모든 의무가 확정되는 것도 아닙니다. 이 검토는 현재 코드와 확인한 공급자 설명을 바탕으로 한 운영 문안 검토입니다.

우선 실제 동작을 설명하는 `서비스·데이터 안내`를 준비하는 것이 적절합니다. 이를 완성된 법정 `개인정보 처리방침`으로 게시하려면 운영자 명칭·실제 연락 창구, 처리 목적·항목·보유기간, 외부 처리 관계, 정보주체 권리 행사 방법 등을 실제 운영과 대조해 확정해야 합니다. 분석 도구·회원가입·문의 폼을 새로 도입하면 다시 검토합니다.

법령 근거: [개인정보 보호법 제30조, 2026-09-11 시행본](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025127663).
